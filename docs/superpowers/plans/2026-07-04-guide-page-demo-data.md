# Guide Page + Demo Data Implementation Plan

> Spec: `docs/superpowers/specs/2026-07-04-guide-page-demo-data-design.md`. Small
> feature; executed inline by the controller (content-authorship work — the guide
> prose depends on whole-system knowledge). Gates per task; browser verification
> mandatory (frontend-runtime-verification lesson).

**Goal:** In-app Guide page (route `/guide`, sidebar entry) + deterministic demo
data (roster CSV, exam PDF with answer-sheet template page, 40-page shuffled scan
pile with varied answer quality) generated by a committed uv script.

## Task 1: Demo-data generator + committed outputs

- Create `scripts/make-demo-data.py` (reportlab; RNG seeded 46; A4): roster CSV
  (10 synthetic students, header `student_id,name,email`); `demo-exam.pdf` (page 1
  answer-sheet template with EMPTY header boxes at student-ID x .05–.30, name
  x .35–.60, problem x .65–.90, y .02–.08 top strip + instructions; pages 2–5 the
  four problems); `demo-scan-pile.pdf` (10×4 pages shuffled; filled header boxes;
  answer bodies deterministically mixed ~50/15/15/10/10 plausible/wrong/short/
  blank/garbled, keyed per (student, problem)).
- Makefile target `demo-data:` running `uv run --with reportlab python scripts/make-demo-data.py`.
- Run it; commit script + `data/demo/*` outputs.
- Verify: page counts (exam=5, pile=40), CSV row count, deterministic re-run (byte-identical).

## Task 2: Guide page

- `frontend/src/pages/GuidePage.tsx` — five anchored sections per spec §1 using
  `Card`; pipeline strip as flex divs; component reference as a definition list;
  demo walkthrough referencing `data/demo/` filenames and `make demo-data`.
- `App.tsx`: route `/guide`; sidebar nav entry "Guide" after Regrades.
- Gate: `npm run typecheck && npm run build`.

## Task 3: Verification + commit

- Rebuild binary (`make frontend && make build`), restart preview server.
- Browser: `/guide` renders all five sections, anchors work, zero console errors.
- Live pile test: fresh assessment (4 problems), import demo roster via UI/API,
  draw regions (template positions), upload `demo-scan-pile.pdf` with OCR off,
  confirm 40 pages render → orphans; spot-assign one page; confirm matrix.
- Commit in two commits (script+data, frontend), pathspecs.
