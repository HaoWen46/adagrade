# UX Fixes (July 2026 audit) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the confirmed professor/TA usability failures from the 2026-07-10 audit: make the grading workflow discoverable from inside an assessment (Gradescope-style Overview dashboard), remove the mask-review grind, surface the final-source step, ship the promised pricing UI, and clean up the worst jargon/dead-ends.

**Architecture:** Frontend-heavy. The keystone is (a) assessment tab state moves into the URL (`?tab=`), making every tab linkable, and (b) a new **Overview** tab (default) that renders the pipeline as a numbered checklist with live status derived from existing APIs plus next-action links. Backend adds exactly three things: a bulk mask-accept endpoint, problem *numbers* in the scan-matrix payload, and `EnsureSeeds` re-run on provider changes. Email/regrade work adds the reply-format block to the grade email and tolerant `<pN>` tag matching.

**Tech Stack:** Go 1.26 (stdlib + sqlc + River), React 19 + react-router 7 + TanStack Query 5, Tailwind 4. Decimal money/points are strings end-to-end (`lib/decimal.ts`; never parseFloat/float64).

## Global Constraints

- New Go logic is **test-first** (CLAUDE.md). Frontend has no test runner; gate with `npm run typecheck` + browser verification by the orchestrator.
- **Do not commit or push** — the orchestrator commits at the end (parallel agents share the tree).
- Never log/commit student PII.
- sqlc: queries in `internal/store/queries/*.sql`, regenerate with `make sqlc` (schema = `migrations/`, output `internal/store/db`).
- Integration tests: `docker compose up -d --wait db-test` then `ADAMARKER_TEST_DATABASE_URL=postgres://adamarker:adamarker@localhost:5434/adamarker_test?sslmode=disable go test ./internal/... -count=1 -run <Name>`.
- Match surrounding style; use existing `ui.tsx` primitives (`Button`, `Badge`, `Card`, `Dialog`, `Field`, `Select`, `Table`, `HelpTip`).
- **Shared seam — URL tabs:** after Task 1, the assessment tab is `searchParams.get("tab") ?? "overview"`. Any component navigates tabs with plain links: `/assessments/{id}?tab=<key>`. Tab keys: `overview, problems, submissions, identify, masking, review, consensus, analysis, regrades, totals, publish`.
- **Shared seam — labels:** `frontend/src/lib/labels.ts` (new, Task 6a) exports `answerStatusLabel(s: string): string` and `flagLabel(s: string): string`; other tasks must NOT create competing helpers.
- Intermediate states may not typecheck until all parallel tasks land; the final verify gate is `make vet && make test && cd frontend && npm run typecheck && npm run build`.
